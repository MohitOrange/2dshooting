# Neon Brawl

Fast top-down arena shooter for Android, made with **Unity 6 (6000.5.8f1, URP 2D)** by MohitGames.

- Offline matches against bots, online rooms with friends (Unity Relay + Lobby), text chat, emotes and voice chat (Vivox)
- 11 guns + knife and grenades, 5 maps, locker, shop, daily rewards and missions
- Realistic layered sound effects generated by `Tools/Sfx/gen-sfx.js` (`node Tools/Sfx/gen-sfx.js`)
- Ads: Google AdMob (+ Unity Ads through AdMob mediation), Google consent form (UMP)
- In-app purchases: Unity IAP

## Open and build
1. Open the folder in Unity Hub with Unity **6000.5.8f1** (Android Build Support installed).
2. Open `Assets/_Project/Scenes/Game.unity` and press Play.
3. Builds: menu **Neon Brawl ▸ Build ▸ Final** (test-ads APK, release APK, Play Store AAB when the upload key is set up, Windows).
